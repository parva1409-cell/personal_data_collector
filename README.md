👤 Personal Data Collector

A simple and beginner-friendly Python project that collects personal information from the user and demonstrates basic Python concepts. 🐍

📌 About

Personal Data Collector is a console-based Python program that asks the user to enter:

👤 Name

🎂 Age

📏 Height in meters

🔢 Favourite number

The program then displays the entered information along with its data type and object ID.

It also calculates an approximate birth year and demonstrates type conversion.

✨ Features

📝 Takes input from the user

🔢 Uses int() and float()

🧮 Calculates approximate birth year

🔍 Displays variable data types using type()

🆔 Displays object IDs using id()

🔄 Converts height from float to int

💻 Runs directly in the terminal

🌱 Beginner-friendly project

🧠 Python Concepts Used

This project demonstrates:

Variables

User input

print() function

🛠️ Requirements

🐍 Python 3.x

No external libraries are required.

▶️ How to Run

Install Python 3 if it is not already installed.

Clone or download this repository.

Open the project folder in your terminal.

Run the program:

python person_data_collector.py

Or, on some systems:

python3 person_data_collector.py
